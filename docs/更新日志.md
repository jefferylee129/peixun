## v1.5 行业对标优化第二轮(2026-11-25)

对标企业学习平台"岗位学习地图/自动触达/移动签到"与国企经费合规、证书防伪、巡察归档要求,新增五项能力(2 张新表 + 课表/证书加列 + `sql/upgrade-v1.5.sql`):

### 岗位学习地图(必修课包)

- 培训管理 → 学习地图配置:按**人员类型**(管理干部/专业技术人员/一般员工)勾选年度必修课程(仅已发布课程),按类型一键保存(覆盖式,幂等);
- 个人事务 → 我的学习地图:必修清单 + 逐课完成状态 + 完成率仪表盘 + "找班次"引导;
- 完成口径与学时台账唯一口径一致:该课程存在**已认定学时**即完成,不另设第二口径;
- 工作台全员可见"岗位必修课"进度卡;配置页按类型展示适用人数/全部完成人数/平均完成率;
- 未发布课程不可设为必修;课程下架后必修清单保留并标注,不悄悄缩水。

### 培训经费预算执行看板

- 统计分析页新增「经费执行」:计划预算(当年已批准计划合计)vs 班次经费(当年开班且未取消,按开班日期归年)、执行率、计划外班次经费;
- 按主办部门双柱对比图 + 按计划明细表(超预算红色标识);
- 口径说明内置于页面提示,避免误读为财务实付。

### 定时自动提醒

- 每日 08:30 自动扫描三类事项并推送站内消息:**开班提醒**(默认提前 3 天提醒已报名学员)、**评估催办**(结班满 3 天未评估)、**学时预警**(复用黄/橙/红规则,约每月触达一次);
- 幂等去重:同类提醒同一业务对象在窗口内(7/28 天)不重复发送(`biz_notify_log`);
- 参数开关 `notify.enabled` 与提前天数可配;消息中心提供"执行提醒扫描"手动触发入口(不受开关限制)。

### 签到码自助签到

- 排课自动生成 6 位签到码,班次详情页对管理员可见并可一键刷新(旧码即失效);
- 员工在「我的班级」对进行中班次输入签到码自助签到,后端按码定位课节(员工端不下发课节列表与签到码);
- 防代签与防篡改:仅限本班学员(不自动入班)、仅限课节当日、管理员登记的请假/缺勤学员不可凭码改勤、编辑课节不可改码、签到类型按时间自动判定(晚于上课时间记迟到,沿用迟到系数);
- 自助签到进入既有"签到→结课折算学时"链路,不引入第二口径。

### 证书防伪查验与档案归档导出

- 公开查验接口 `/public/certificates/verify`(无需登录):**证书编号 + 防伪码**双要素匹配(防伪码 6 位,发证时随机生成并印于证书),防止编号被顺序枚举;
- 响应脱敏(姓名仅留首字、工号仅留后四位);每 IP 每分钟 10 次限流(超限 429);不存在/码错/已作废统一返回"未查询到有效证书",不给探测信号;
- 个人事务 → 证书查验:任何人可在线核验证书真伪;
- 一人一档导出:档案页新增「导出档案」,生成四 Sheet Excel(基本信息/参训班次/结业证书/考试成绩),权限为本人或查他人档案权限,供巡察归档。

### 新增测试与修复

- deep-test 新增 D14-D18 共 **31 断言**(学习地图/经费/提醒去重/自助签到九连测/查验与导出);
- 开发期发现并修复:自助签到控制器重复调用业务方法(评审发现)、课节编辑接口可篡改签到码(改为仅刷新接口可改)、非学员管理员代签入口收紧为预览(v1.4 已含);
- 回归结论:e2e 67/67、excel 30/30、integration 17/17、**deep 242/242**。

## v1.4 安全加固(2026-11-22,`08e2c17`)

### 漏洞修复(5 项,均已回归验证)

| # | 漏洞 | 影响 | 修复 |
| --- | --- | --- | --- |
| 1 | 考试"及格计学时"未校验非负 | `hourReward=-2` 可向学时台账写入负数,拉低年度统计 | 保存考试强制非负 |
| 2 | 交卷接口存在管理员绕过 | 管理员可非学员身份"代考",生成成绩与学时污染学员台账 | 交卷严格校验班次学员身份;管理员改为预览模式(不建作答记录、不产生成绩) |
| 3 | 并发双交卷竞态 | 成绩与及格学时可能双发 | 原子守卫 `UPDATE ... WHERE submit_time IS NULL`,并发实测恰好一次生效 |
| 4 | 超长输入返回 500 | 题干/解析/考试名/公告超长直接触发数据库异常 | 按列宽服务端校验,统一返回 400 |
| 5 | 单选答案数据缺陷 | 答案 "AA" 可通过校验但永无人得满分 | 单选答案强制单字符且必须在选项中 |

### 新增测试

### 回归结论

## v1.3 行业对标优化(2026-11-22,`2337cb1`)

对标云学堂 / UMU / 时代光华企业学习平台与国企干部培训档案要求,新增四个模块(5 张新表 + `sql/upgrade-optimize.sql`):

### 一人一档培训档案

- 聚合形成个人培训履历:基本信息、年度学时(含签到/补录/外部/线上来源构成)、参训班次、评估记录、结业证书、考试成绩、倒序时间线;
- 员工查自己(个人事务 → 我的档案),管理员/培训管理员查全员(培训管理 → 培训档案,支持姓名/工号检索);
- 已删除班次的历史作答显示"(班次已删除)",留痕完整。

### 消息中心与学时预警

- 六类站内消息:**达标预警 / 报名开班 / 评估催办 / 结业证书 / 考试 / 系统公告**;业务动作自动触达——发布报名通知全员、开始培训通知学员、结班催办未评估学员、发证/发布考试/成绩发布点对点通知;
- 顶栏铃铛未读红点(30 秒轮询),单条已读与一键全部已读;管理员可发全员公告;
- **学时分级预警**:年度时间进度 50%/75%/90% 对应学时进度不足 30%/50%/70% 分黄/橙/红三级(参数 `warn.ratio.mid/q3/end` 可配);工作台个人预警条 + 管理员全员预警名单 + 一键推送提醒。

### 结业证书

- 班次结班时自动对"已完成"学员发证,编号 `QGPX-YYYY-XXXXXX`;
- 班次+人员唯一,支持幂等补发(已发自动跳过);证书预览与打印视图;颁发即站内通知。

### 在线考试(柯氏二级·学习层落地)

- **题库**:单选/多选/判断三类题型,选项 JSON 化,可关联课程;答案越界与非法答案强校验,被考试引用的题目禁止删除;
- **组卷**:考试挂班次,从题库选题,时长/总分/及格线/及格计学时可配,未选题拒绝保存;
- **状态机**:`0 草稿 → 1 已发布 → 2 已截止`,发布即通知班次学员;
- **作答**:取卷开始计时(与作答窗口取早者),超时自动交卷;一人一卷、重复交卷拒绝;试卷不下发答案;
- **判分**:自动阅卷,及格按"线上学习"来源直接认定学时(同考仅一次),成绩进档案并推送消息;管理员可查成绩单(交卷/及格人数、逐人分数)。

### 新增测试与菜单

- `tests/deep-test.sh` 新增 D11(档案/预警/消息)+ D12(证书/考试)共 41 断言;
- 新菜单:培训档案(600)/题库管理(601)/考试管理(602)/证书台账(603)/我的档案(604)/消息中心(605)/在线考试(606)及 5 个按钮权限,培训管理员与普通员工角色已分配。

### 开发期发现并修复的缺陷

1. `biz_certificate.cert_no` NOT NULL 与"先插后回填编号"冲突导致发证 500 → 改列可空;
2. Lombok 双大写字段 `qType` 被 Jackson 推导为 `qtype`,入参绑不上出参键名错 → `@JsonProperty("qType")` 显式指定;
3. 升级脚本中文乱码 → mysql 客户端需加 `--default-character-set=utf8mb4`(脚本头部已加提醒)。

### 回归结论

e2e 67/67、excel 30/30、integration 17/17、**deep 180/180**;浏览器实测档案/消息/考试/管理端页面。

## v1.2 深度测试与修复(2026-11-13,`0c81eda`)

以 139 项深度断言打穿既有套件未覆盖的业务规则,修复系统缺陷 9 类:

- **学时重算 500(高危)**:`@TableLogic` 软删行与 `uk_hour_schedule_user` 唯一键冲突,补签/结班第二次重算必报 Duplicate entry → 签到派生学时改物理删除;
- **内派班走不通**:筹备中不能直接开始 → 放行 `0(筹备)→2(进行中)` 跳过报名;
- **评估均分口径错**:整体均分返回"人均总分" → 改为评分项算术平均;
- **需求审核参数分裂**:`adopt` 与其他审核的 `pass` 不一致 → 兼容两者;
- **学时 keyword 不搜备注** → 追加备注模糊匹配;
- 其余:停用/删除用户旧 token 立即失效、并发报名行锁防超卖、日期倒挂校验、外部来源标记不可篡改、用户删除关联校验、征集重复关闭与有申报删除拦截、数据源状态枚举与忽略存在性校验;
- deep-test.sh 脚本缺陷全修(中文编码、List 取 ID、映射传参、登录 ERR 终止等);e2e 5.13-5.15 联动补签/缺勤断言(65 → 67 用例)。

回归结论:e2e 67/67、excel 30/30、integration 17/17、deep 139/139。

## v1.0 系统初版(2026-10-31,`fcd04a5`)

围绕"**需求征集 → 计划编制 → 课程/师资 → 开班实施 → 签到计学时 → 评估改进**"的 PDCA 闭环,按 ISO 10015、
《干部教育培训工作条例》(学时 110/90 可配置)与柯氏四级评估设计:

| 模块 | 功能 |
| --- | --- |
| 工作台 | 统计卡片、月度学时趋势、课程分布、部门学时、我的学时进度 |
| 培训需求 | 年度征集任务、员工申报、审核采纳/驳回、需求台账 |
| 培训计划 | 年/季/月/专项计划、提交审批、批准下达、驳回重报 |
| 培训课程 | 课程库、起草-审核-发布-下架状态流、被引用课程保护 |
| 培训师资 | 内部讲师/外部专家、讲师等级、授课档案与累计学时 |
| 培训班次 | 开班、报名(自主+指定)、排课节次、状态流转、签到自动入班容量校验 |
| 签到与学时 | 按节次签到(正常/迟到/请假/缺勤)、结课折算学时(迟到系数可配)、手工补录、外部认定、认定流 |
| 学时达标 | 按人员类型年度要求、达标率统计、部门维度统计 |
| 培训评估 | 柯氏四级模板(打分项+开放题)、在线作答、逐项/总体均分汇总 |
| 统计分析 | 覆盖率、人均学时、计划完成率、多维图表 |
| 系统管理 | 用户/部门/角色/菜单(RBAC)、参数配置、操作日志审计、Excel 导入导出(逐行校验、幂等跳过) |

安全基线:BCrypt 密码、JWT 认证、`@RequirePerm` 接口权限、`@OperLog` 全量操作留痕(密码脱敏)、登录失败锁定、分页钳制、SQL 全参数化。
