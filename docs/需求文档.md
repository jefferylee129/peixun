# 国企培训管理系统 · 需求文档(需求规格说明书)

> 版本:v1.5(2026-11-25) · 状态:与已实现系统一致
> 本文按"角色 → 业务流程 → 功能需求(FR 编号) → 非功能需求 → 需求追溯"组织,记录系统**应有什么、规则是什么、如何算满足**。
> 技术实现细节见 [设计方案.md](设计方案.md),版本演进见 [更新日志.md](更新日志.md),验收证据见 [测试报告.md](测试报告.md)。

## 1. 引言

### 1.1 目的与范围

为国有企业提供覆盖"**需求征集 → 计划编制 → 课程/师资 → 开班实施 → 签到计学时 → 评估改进**"全流程的培训管理系统,满足:

- 学时刚性约束(干部教育培训学时要求,可配置);
- 分级授权与审批留痕(巡视巡察、内控审计);
- 行业优秀实践对标(企业学习平台的必修课地图/自动触达/移动签到/考试,证书防伪查验,经费合规看板)。

### 1.2 读者

培训管理员(业务运营)、各级管理者(统计与审批)、员工(自助事务)、信息系统运维与审计人员。

### 1.3 术语

| 术语 | 含义 |
| --- | --- |
| 学时台账 | 个人年度培训学时的唯一统计口径(仅"已认定"记录) |
| 柯氏四级 | 反应层/学习层/行为层/结果层四类评估 |
| 必修课 | 岗位学习地图中按人员类型配置的年度必修课程 |
| 防伪码 | 结业证书上的 6 位校验码,公开查验需与编号双要素匹配 |

## 2. 用户角色与权限

| 角色 | 权限范围 |
| --- | --- |
| 超级管理员 admin | 全部功能与系统管理 |
| 培训管理员 training_admin | 全部培训业务(需求/计划/课程/师资/班次/学时/评估/考试/证书/档案/地图/同步/提醒) |
| 普通员工 employee | 需求申报、自主报名、自助签到、评估作答、在线考试、我的学时/档案/学习地图、消息中心、证书查验 |

- 认证:JWT(24h),**停用/删除用户后旧令牌立即失效**【v1.2】;
- 授权:菜单/按钮级权限标识(`@RequirePerm`),员工越权访问管理接口返回 403;数据范围在服务层按登录人收敛("我的"接口只看本人)。

## 3. 业务流程总览

```
需求征集 → 需求申报 → 需求审核 ─┐
                              ├→ 年度计划编制 → 审批下达 ─→ 开班(关联计划)
              课程库/师资/外部课程同步 ┘        │
                                              ↓
            签到(管理员登记/员工签到码自助) → 结课折算学时 → 结班
                                              ↓
        结业证书自动发放 → 评估催办/在线考试 → 学时达标统计与预警 → 学习地图完成度
                                              ↓
                                    一人一档归档与导出 → 反哺下一年度需求
```

## 4. 功能需求

> 编号规则:`FR-模块-序号`;每条含需求描述、关键业务规则(括注)与验收要点。标注引入版本。

### FR-01 工作台【v1.0】【v1.3 增强】【v1.5 增强】

1. 统计卡片:班次总数、进行中、已发布课程、年度学时总量、人均学时、覆盖率、计划完成率;
2. 月度学时趋势/课程分布/部门学时图表(管理端);
3. 我的年度学时进度环与达标状态【v1.0】;
4. 个人学时预警条(黄/橙/红)与全员预警名单、一键推送(管理端)【v1.3】;
5. **岗位必修课进度卡**(全员可见:已完成 x/y、完成率,跳转学习地图)【v1.5】。

验收:员工登录即可见必修课卡;预警仅对触发者显示;全员预警仅 `biz:archive:other` 可见。

### FR-02 培训需求管理【v1.0】

1. **征集任务**:培训管理员发起(标题/年度/起止时间),全员可见;关闭后不可重复关闭;有申报记录不可删除;
2. **需求申报**:员工填报(类别:党性教育/管理能力/岗位技能/安全合规/通用素质),草稿→提交→审核状态机;他人不可改/删(属主校验);已采纳/已提交不可删;
3. **审核**:采纳/驳回并留痕(审核人/时间/意见);
4. 台账与 Excel 导入导出。

### FR-03 培训计划管理【v1.0】

1. 计划类型:年度/季度/月度/专项,含预算(万元);
2. 状态机:`0 草稿 → 1 待审批 → 2 已批准 / 3 已驳回`;仅草稿/驳回可编辑、提交、删除;日期倒挂拒绝;
3. 已批准计划方可关联开班(下拉选项);
4. 计划完成率纳入统计。

### FR-04 培训课程与师资【v1.0】

1. 课程五类分类、内训/外训/线上形式、标准学时、大纲;状态机 `草稿→待审核→已发布→下架`;已发布不可编辑(须先下架)、被课表引用不可删;
2. **外部来源课程(sourceType/externalCode)不可通过编辑篡改**【v1.2】;
3. 师资:内部讲师/外部专家、等级、授课档案与累计授课学时;被引用讲师不可删。

### FR-05 培训班次与签到【v1.0】【v1.2/1.5 增强】

1. 开班:名称、类型、主办部门、关联计划、起止日期(倒挂拒绝)、地点、容量、经费;创建返回班次 ID【v1.5】;
2. 状态机:`0 筹备 → 1 报名 → 2 进行 → 3 结束`,`0/1` 可取消;**筹备中可直接开始**(内派班跳过报名)【v1.2】;
3. 学员组织:管理员批量指定 / 员工自主报名(仅报名中、容量校验、防重复);
4. 排课(节次):课程、讲师、日期、起止时间、节学时;结班自动结束未上课节;已结束/取消班次不可再排课、改课表;
5. **签到与计学时**(核心):
   - 管理员按节次登记:正常/迟到/请假/缺勤;签到自动入班受容量约束(行锁防并发超卖);
   - 结课折算:正常=节学时,迟到=节学时×迟到系数(默认 0.5 可配),请假/缺勤=0;结果写入学时台账(来源=签到);
   - **课节结束后班次进行中允许补签,补签立即重算**(幂等);结班时无学时报名学员自动标缺勤;
6. **签到码自助签到**【v1.5】:
   - 排课自动生成 6 位签到码,同班次内唯一;管理员可见、可刷新(旧码即失效);
   - 员工在「我的班级」输入签到码自助签到,后端按码定位课节;**签到码不下发学员端**;
   - 规则:仅本班学员(不自动入班)、仅课节当日、课节未取消/未结束、码匹配;**管理员登记的请假/缺勤不可被学员凭码改勤**;重复签到拒绝;签到类型按时间自动判定(晚于上课时间记迟到);
   - 自助签到进入既有"签到→结课折算学时"链路,不引入第二口径。

验收:deep-test D5/D6/D17 全过(容量并发、补签重算、自助签到九项规则)。

### FR-06 学时台账与达标【v1.0】【v1.3 增强】

1. 台账唯一口径:个人年度学时 = 已认定记录之和;来源四种:1 签到自动 / 2 手工补录 / 3 外部认定 / 4 线上学习(考试及格);手工入口收敛为 2/3,来源 1 仅系统生成【v1.2】;
2. 认定流:补录/外部认定先"待认定",管理员认定/驳回;非法来源规范为手工补录;已认定不可删、不可重复认定;
3. 达标管理:按人员类型配置年度要求(管理干部 110/专业技术人员 90/一般员工 90,参数可配),达标率与进度;**keyword 支持按备注检索**【v1.2】;
4. **学时分级预警**【v1.3】:年度时间进度 50%/75%/90% 对应学时进度不足 30%/50%/70%(参数 `warn.ratio.*` 可配)分黄/橙/红;工作台个人预警 + 管理员全员名单 + 一键推送;历史年度未达标记红色。

### FR-07 培训评估(柯氏四级)【v1.0】【v1.2 修正】

1. 模板按四级分级,条目 JSON 化(打分项 1-5 必填 / 开放题),可启停;已有作答的模板条目冻结;
2. 学员对进行中/已结束班次作答,一人一卷可覆盖更新,非本班学员拒绝,评分越界拒绝;
3. **班次评估仅允许一级(反应层)模板**;
4. 汇总:逐项均分、**总体均分=全部评分项算术平均**【v1.2 修正,原为人均总分】、参评人数去重、开放意见明细。

### FR-08 在线考试(柯氏二级·学习层)【v1.3】【v1.4 加固】

1. **题库**:单选/多选/判断;选项 JSON;答案强校验(单选单字符且在选项中、判断仅对/错、多选按集合比对);被考试引用的题目禁止删除(可停用);
2. **组卷**:考试挂班次、从题库选题(未选题拒绝)、时长(≤240 分钟)/总分/及格线/**及格计学时(非负)**可配;
3. **状态机**:`草稿 → 已发布 → 已截止`;发布通知班次学员;已发布不可编辑/删除;仅草稿可截止;
4. **作答**:取卷开始计时(与作答窗口取早者),超时自动按已存答案交卷;一人一卷、重复交卷拒绝(原子守卫);试卷不下发答案;**仅本班学员可作答(管理员无学员身份仅可预览,不产生成绩)**;
5. **判分与激励**:自动阅卷,及格按"线上学习"来源认定学时(同考仅一次),成绩推送消息并进入档案。

### FR-09 结业证书与防伪查验【v1.3】【v1.5 增强】

1. 班次结班自动对"已完成"学员发证,编号 `QGPX-YYYY-XXXXXX`;班次+人员唯一;幂等补发;颁发即站内通知;
2. 证书预览/打印视图(含防伪码)【v1.5】;
3. **公开防伪查验**【v1.5,无需登录】:
   - 双要素:`证书编号 + 防伪码(6 位,发证随机生成,印于证书)` 同时匹配;
   - 脱敏:姓名仅保留首字、工号仅保留后 4 位;
   - 限流:每 IP 每分钟 10 次,超限 429;
   - 编号不存在/防伪码错误/已作废统一返回"未查询到有效证书"(不给探测信号)。

### FR-10 一人一档培训档案【v1.3】【v1.5 增强】

1. 聚合:基本信息、年度学时(含来源构成)、参训班次、评估记录、证书、考试成绩、倒序履历时间线;
2. 员工查本人;`biz:archive:other` 查任意人(支持姓名/工号检索);已删除班次的历史记录标注"(班次已删除)"保留留痕;
3. **归档导出**【v1.5】:四 Sheet Excel(基本信息/参训班次/结业证书/考试成绩);权限=本人或查他人档案权限,越权拒绝。

### FR-11 消息中心与自动提醒【v1.3】【v1.5 增强】

1. 六类站内消息:达标预警 / 报名开班 / 评估催办 / 证书 / 考试 / 系统公告;顶栏未读红点(30 秒轮询),单条已读/全部已读;标记他人消息拒绝;管理员可发全员公告(标题必填、长度校验);
2. 业务自动触达:发布报名通知全员、开始培训通知学员、结班催办未评估学员、发证/发布考试/成绩发布点对点通知【v1.3】;
3. **定时自动提醒**【v1.5】:每日 08:30 自动扫描——开班提醒(提前 3 天提醒已报名学员)、评估催办(结班满 3 天未评估)、学时预警(按 FR-06 分级,约每月一次);
4. **去重**:同类提醒同一业务对象在窗口内(7 天/28 天)不重复发送;开关 `notify.enabled` 可配;管理员可手动触发(不受开关限制)。

### FR-12 岗位学习地图(必修课包)【v1.5】

1. 配置:按人员类型(管理干部/专业技术人员/一般员工)勾选**年度必修课程**,仅已发布课程可选;按类型覆盖式保存(幂等);未发布课程拒绝;清空合法;
2. 我的必修:清单含课程编码/分类/学时/完成标记;**完成判定 = 该课程存在已认定学时**(与台账唯一口径一致);课程下架后清单保留并标注;
3. 统计:各类型适用人数、全部完成人数、平均完成率(管理端);
4. 工作台全员必修进度卡(见 FR-01)。

### FR-13 培训经费预算执行【v1.5】

1. 口径:计划预算 = 当年**已批准**计划预算合计;班次经费 = 当年开班(按开班日期归年)且**未取消**班次经费合计;执行率 = 班次经费/计划预算;
2. 输出:总量三指标 + 计划外班次经费单列;按主办部门双柱对比;按计划明细(班次数/预算/经费/执行率/超预算标识);
3. 页面口径提示内置,防止误读为财务实付;权限 `biz:stats:view`。

### FR-14 统计分析【v1.0】

覆盖班次状态/计划状态/需求类别/课程分类分布、月度学时趋势、部门学时、员工学时达标表(含 CSV 导出);全部管理端权限 `biz:stats:view`。

### FR-15 外部课程同步【v1.1】

1. 数据源三类型:云学堂(OAuth2+分页)/ 通用 REST(字段映射、分类映射可配)/ 演示数据源(离线 8 门);测试连接优雅反馈;
2. 同步进"待入库"池,`(source_id, external_id)` 唯一幂等;审核入库(外部来源标记不可篡改)、可忽略;拉取/入库/测试全程日志留痕;App Secret 全程脱敏;
3. 状态枚举校验、忽略不存在暂存课拒绝【v1.2】;停用数据源禁止同步。

### FR-16 系统管理【v1.0】【v1.2 加固】

用户/部门树/角色/菜单(RBAC)、系统参数(学时要求/迟到系数/预警阈值/提醒开关与天数)、操作日志审计(**密码脱敏**);用户删除校验学时/学员/需求关联;内置管理员不可停用/重置密码保护;用户状态枚举校验;Excel 导入导出(逐行校验、幂等跳过)。

### FR-17 登录与账户安全【v1.0】【v1.2 加固】

BCrypt 密码;登录失败 5 次锁定 10 分钟;超大分页钳制(页码≥1、单页≤200);重置密码保护内置管理员;**停用/删除用户旧 token 立即失效**。

## 5. 非功能需求

| 类别 | 需求 |
| --- | --- |
| 安全 | 全部 SQL 参数化(`#{}`,禁 `${}`);JWT 过期与令牌即时失效;接口权限注解全覆盖;越权 403(HTTP 200 + body code 403,未认证 401);公开接口(证书查验)脱敏 + IP 限流;5xx 对外固定文案不泄漏内部细节 |
| 审计 | 全部写操作经 `@OperLog` 记录操作人/IP/参数/结果;敏感字段(password/appSecret)脱敏 |
| 数据一致性 | 核心防重唯一键(考勤/学员/学时/证书/作答/学习地图)+ 冲突原子处理;派生数据(签到学时)重算走物理删除避免软删与唯一键冲突;余额类操作(容量/交卷)用行锁或原子守卫 |
| 性能 | 分页统一钳制;统计聚合 SQL;前端图表随窗口自适应 |
| 可配置 | 学时要求、迟到系数、预警阈值、提醒开关与天数均为系统参数,无需改码 |
| 可运维 | 增量升级 SQL 幂等(schema/data/upgrade-*);四套自动化回归一键复跑;演示数据源离线可用 |
