日期:2026-10-31 · 方法:独立代码审查(审阅者代理) + 静态排查 + 自动化接口测试(65 用例) + 回归验证

## 二、发现并修复的问题(13 项)

### 安全类
1. **横向越权**:提交/删除需求接口未校验属主,任何用户可把他人草稿推入审核队列 → 补属主校验(管理员放行);
2. **明文密码落审计日志**:`@OperLog` 切面把请求体原样写入 `sys_oper_log.params` → 切面统一脱敏 `password/oldPassword/newPassword`(实测日志中为 `***`,全表 0 泄漏);
3. **登录无爆破防护** → 增加"同账号 5 次失败锁定 10 分钟"(内存实现,集群可接 Redis),连错 5 次后正确密码也返回 429(实测通过);
4. **500 响应泄漏内部异常细节**(SQL 片段/表名) → 对外统一固定文案,详情仅写服务端日志;补 `NumberFormatException` 等参数错误 → 400;
5. **JWT 密钥/数据库口令硬编码** → 改为环境变量注入(`TRAIN_JWT_SECRET`、`TRAIN_DB_PASSWORD/HOST/USER`),带开发默认值;
6. **越权接口**:课程删除未检查课表引用 → 已引用课程禁止删除。

### 业务规则类
7. **签到可绕过人数上限**(签到自动入班无容量校验)→ 补容量校验;
8. **已结束/已取消班次仍可改课表、结课、重算学时**(学时可被事后篡改)→ 课节写操作统一校验父班次状态,结课要求班次进行中;
9. **课节结束后仍可补签** → 禁止;
10. **学时来源可被伪造为"签到自动"且会被重算误删** → 手工入口来源收敛为 2 补录/3 外部认定;
11. **评估必填项仅前端约束** → 服务端强制必填评分项;已有作答的模板条目冻结(防历史作答与条目错位);
12. **更新用户不传 roleIds 会清空角色** → 仅显式传入才重新分配(实测角色保留);
13. **重置密码可重置内置管理员(接管超管)** → 拦截 id=1。

### 健壮性
14. **并发竞态**:签到/报名为 select-then-insert,并发重复产生双份考勤与双倍学时 → `biz_attendance(schedule_id,user_id)`、`biz_class_student(class_id,user_id)`、`biz_hour_record(schedule_id,user_id)` 加唯一索引 + 冲突改更新 + 移除学员改物理删除;
15. **分页无上限**:`?size=-1` 触发全表拉取 → 统一 `PageQuery.of()` 钳制(页码≥1、单页≤200),替换全部 16 处直构;
16. **结班收尾**:未参训学员自动标记"缺勤",学员/课表状态口径完整;
17. **评估模板接口健壮性**:`items` 兼容 JSON 字符串与原生数组两种传参(原仅字符串,传数组报 500)。

## 三、确认干净项

- **SQL 注入**:全部 `@Select` 使用 `#{}` 预编译,全库无 `${}` 拼接、无 XML Mapper;注入用例实测被拒;
- **管理接口权限注解**:15 个 Controller 管理端点均有 `@RequirePerm`,拦截器仅放行 `/auth/login` 与 `/error`;
- **XSS**:前端无 v-html,Vue 默认转义;
- **越权读**:学时/评估"我的"接口均按登录人过滤;员工访问管理接口均 403。

## 四、遗留与建议(不阻塞交付)

1. 默认口令统一(admin123/user123)上线时必须改密;"强制首登改密"建议列入后续迭代;
2. 登录锁定为单机内存实现,集群部署改用 Redis;退出登录 Token 未拉黑(无状态 JWT 固有,可加黑名单);
3. CORS 当前全开放(无凭据场景可接受),生产按域名收紧;
4. 评估允许覆盖重交(未设时间窗),是否限制由培训制度确定。
